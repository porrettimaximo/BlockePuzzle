# Block Puzzle Jewel (Java)

**Block Puzzle Jewel** es un juego de lógica y estrategia donde tenés que colocar piezas de distintos tamaños en un tablero **8x8**.   El objetivo es **completar filas o columnas** para eliminarlas y sumar puntos.  

El juego termina cuando ya no podés colocar ninguna pieza.
