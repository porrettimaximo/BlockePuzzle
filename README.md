# Block Puzzle Jewel (Java)

**Block Puzzle Jewel** es un juego de lógica y estrategia donde tenés que colocar piezas de distintos tamaños en un tablero **10x10**.  
El objetivo es **completar filas o columnas** para eliminarlas y sumar puntos.  
A medida que el tablero se llena, planificá tus movimientos para no quedarte sin espacio.  
El juego termina cuando ya no podés colocar ninguna pieza.
